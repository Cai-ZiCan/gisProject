# GIS Project Frontend (前端可视化)

本目录包含基于 Web 的 GIS 前端应用，主要负责地图交互、参数输入与结果展示。

## 技术架构

*   **核心库**: OpenLayers v8.2.0
*   **语言**: HTML5, CSS3, Vanilla JavaScript (原生 JS)

## 目录结构

*   `index.html`: 应用主入口页面，包含地图容器与 UI 控件。
*   `js/`: JavaScript 模块化代码。
    *   `config.js`: 全局配置（包括后端 API 地址、GeoServer WMS 地址）。
    *   `layers.js`: 定义地图图层源（WMS 图层配置）。
    *   `layerControls.js`: 图层开关与图例交互逻辑。
    *   `gisAnalysis.js`: **客户端分析代理**。
        *   不直接进行复杂的几何运算。
        *   负责收集用户输入与交互事件（如点击位置、框选范围）。
        *   向 `backend` 发起 AJAX/Fetch 请求，并解析返回的分析结果进行渲染。
    *   `main.js`: 程序初始化入口与事件绑定。

## 功能特性

*   **多图层切换**: 支持街道图、卫星图与不同年份形变场图层的叠加切换。
*   **动态图例**: 根据显示的形变层自动加载对应的图例说明。
*   **交互式弹窗**: 点击地图要素可查看具体属性信息。

## 交互流程
* **gps数据访问**
1.  用户在地图上进行操作（如点击某监测点）。
2.  `gisAnalysis.js` 捕获坐标，调用后端 API。
3.  后端返回形变趋势数据。
4.  前端接收数据并以弹窗或图表形式展示。
